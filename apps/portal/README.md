# Salkaro Portal

Salkaro Portal is a client-facing delivery workspace for agencies and service teams.
It turns internal project data into a clean, shareable portal experience that keeps clients aligned without exposing your internal tools.

## Product Summary

Salkaro Portal helps teams:

- Connect project systems (starting with Monday.com)
- Build client portals from real project boards
- Share progress securely with configurable access
- Control what clients see (status, timeline, owners)
- Manage internal team access and organisation settings

## Who This Is For

- Agencies running multiple client projects
- Teams that need transparent delivery reporting
- Account and project managers sharing progress updates
- Ops leaders who want a repeatable, branded client experience

## Core Product Areas

### 1. Portal Creation

Create a portal in a guided flow:

1. Choose an integration connection
2. Select a source board
3. Pick which fields to import
4. Customize portal name, tagline, and visible sections

### 2. Client-Facing Portal View

Each portal can present:

- A project board view sourced from connected data
- Delivery stat cards (total items, completion %, in-progress, overdue)
- Status breakdown visualizations
- Timeline and owner sections (when enabled)

### 3. Access and Sharing Controls

Portal owners can configure access:

- Anyone with link
- Anyone with code
- Email OTP flow is present in product architecture, with UI toggle currently marked as coming soon

### 4. Integrations

Integration catalog includes:

- Monday.com (available now)
- ClickUp (coming soon)
- Asana (coming soon)
- Linear (coming soon)

Connected integrations can be:

- Added
- Renamed
- Disconnected

### 5. Organisation and Team Management

- Manage organisation profile (name and icon)
- Add and manage employee members
- Generate and manage invite codes
- Role-aware actions for owners/admins

### 6. Workspace Sections

Main workspace navigation includes:

- Dashboard
- Portals
- Clients
- Activity
- Employees
- Integrations
- Settings (General, Organisation, Appearance, Billing)

## Plan Limits

Salkaro Portal currently supports two plans:

| Plan |   Portals | Employees | Integrations |
| ---- | --------: | --------: | -----------: |
| Free |         2 |         1 |            1 |
| Pro  | Unlimited |        10 |    Unlimited |

## Plan Behavior

- Portal creation is blocked when the portal limit is reached
- Member addition is blocked when the employee limit is reached
- Downgraded accounts are prompted to remove excess portals/members before continuing
- Billing supports free-to-paid upgrade flow via Stripe pricing table

## Customer Value

Salkaro Portal is designed to reduce update friction and improve trust:

- Clients get clear visibility into progress
- Teams avoid manual status reporting
- Agencies standardize delivery communication
- Leadership gets consistent operational transparency

## Current Product Status

- Live foundation for portal creation, sharing, integrations, team management, and settings
- Monday.com is the first active integration
